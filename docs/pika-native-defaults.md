# Stable automated Pika Director profile

The Agent/MCP path now keeps the Director's native geometry: **175 frames at 24 fps (~7.29 seconds), 39-frame overlap (1.625 seconds)**. Source checked: TimelineDirector `js/segment_windows.mjs` and Riverfield's existing `h3_planner.py`. The eight segments in the user's screenshot are a timeline count, not a reason to force every request to eight segments.

- `plan_segments` no longer exposes a segment-duration parameter. An approximate `total_seconds:30` returns five native windows, ending at frame 719 (~29.96 seconds). It never asks the model to tune 10/10.5/11 seconds or satisfy a rigid exact-total constraint.
- Pika runtime interview choices are also supplied by this same calculator, before display and before recording the tool call: 7.29 s / 1 segment, 12.96 s / 2, 18.63 s / 3, 29.96 s / 5. The model cannot supply contradictory duration/count labels in these choices. Requested targets remain distinct from actual native durations. Unrelated audio/music duration questions are not changed.
- With missing/wrong prompt count, it returns `ready:false`, the fixed layout and required prompt count, but **no runnable `segment_windows`**. The agent adapts its script, not the geometry. Complete prompts and material assignments pass through unchanged.
- Automated Pika arguments are normalized using the same helper before approval and again at MCP preparation. Pending approvals show the native values; completed jobs and manual Director UI timelines are not rewritten. Raw advanced timeline overrides remain a manual-only operation.
- The agent writes scenarios and segment prompts; chooses six-section Ref2VA with actual visual references or three-section empty-bin FL2VA as supported by this app; binds local pictures and optional audio; and describes native dialogue, ambience/effects and intended music. Installed audio apps may prepare a genuinely needed reference with normal user approval. No new engine, planning system or model is added.
- Passing two files does not automatically select both: a two-reference segment must assign `images:[0,1]`. `audioN` references likewise need the segment's `audios` selection and the correct `audio_mode`.
